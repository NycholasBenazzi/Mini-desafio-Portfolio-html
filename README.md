# Portfólio Web - Desenvolvedor Web
## Sobre o Projeto
Esse projeto foi desenvolvido como parte de um desafio de Desenvolvedor Web, com objetivo de praticar a estruturação de páginas HTML semântica.

A página representa um portfólio de um estudante de Desenvolvimentos de Sistemas, apresentando suas habilidades, projetos e formulário para contato.

## Objetivos 
- Praticar a estrutura básica do HTML5;
- Utilizar tags semânticas;
- Criar uma navegação com links internos;
- Organizar informações em uma tabela;
- Criar um formulário de contato; Trabalhar com imagens, links e lista;
- Desenvolver uma página limpa e funcional.

## Tecnologias Utilizadas 
- HTML - Estrutura e conteúdo da página
- Links HTML - Navegação entre seções e projetos
- Formulário - Área de contato
- Tabelas - Organização dos projetos
